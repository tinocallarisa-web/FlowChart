1. Licence tiers

Free tier Free

Available to every Power BI user at no charge, with every feature unlocked:

  • Data-driven process diagram built from the Levels field wells, with automatic branch merging
  • Horizontal or vertical layout, per-layer centring and crossing-minimisation
  • Cycle detection, drawn as discontinuous loops
  • Dominant path emphasis and top end-to-end variant highlighting
  • Variants panel with the top 8 paths by value
  • Collapse and expand branches, with cascading value recalculation
  • Zoom, native scroll, minimap, in-diagram search and fit to view
  • KPI badges (value against target, with variation %)
  • Swimlane bands across the levels
  • Level images from base64 strings in your model
  • Native selection, cross-filtering, context menu, standard and report page tooltips
  • Keyboard focus and high contrast support
  • The complete Format Pane: layout, nodes, badges, value format, links, swimlanes, legend, data colours

The only limit is size: a Free diagram renders up to 9 nodes, kept as a connected sub-tree from the root so the diagram remains coherent, with a message reporting how many nodes were omitted.
