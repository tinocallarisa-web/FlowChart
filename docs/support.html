Support & Documentation

Version 1.2.0.0 · See what’s new

Flow Chart turns a set of ordered columns into a process diagram. Each column you drop into Levels becomes one stage of the flow, repeated values merge into shared branches, and the Value measure sets the weight of every node and link. Everything below is documented against version 1.2.0.0 of the visual. The visual follows the language of Power BI: English, Spanish, French, German, Italian, Portuguese (Brazil and Portugal), Dutch, Polish, Japanese, Simplified Chinese and Korean.

Quick Start

1. Add the visual to your report

Import Flow Chart from AppSource, or from a .pbiviz file via Insert → More visuals → Import a visual from a file. Drop it onto the canvas and give it room — process diagrams need horizontal space more than height.

2. Build the flow with Levels

Drag one field per stage into Levels, in the order the process happens. Field order is the structure: the first field is the root layer, the second the next layer, and so on. Rows that share the same value at a given level are merged into one node, which is how branches form.

Two fields in Levels are the minimum: with one, the visual asks for a second; with none, it shows a start screen with the three steps and links to this guide. Optionally add a measure to Value: node badges, link thickness and the dominant path are derived from it. Without it, each row counts 1.

While you edit, setup tips at the bottom of the visual show which wells are filled and apply a style template, link labels, level headers or the direction in one click. Close them with ✕; Style template → Show setup tips brings them back. They never appear in reading view.

3. Read the diagram

Nodes are the states, links are the transitions between them, and link thickness is proportional to Value. The dominant path — the heaviest chain through the diagram — is emphasised by default. A transition that goes backwards in the process is detected as a cycle and drawn as a discontinuous loop instead of being forced into the layer order.

4. Add context

These three wells are Pro. A Target measure turns on the KPI badge on each node (actual against target, with the variation percentage). A Swimlane field draws coloured bands across the levels. Measures in Tooltip fields appear on hover without changing the layout.

Interaction

Cross-filtering and selection

Clicking a node or a link filters the rest of the report through the standard Power BI selection model. Ctrl+click adds to the selection; clicking empty space or pressing Escape clears it. Selections made in other visuals dim the parts of the diagram that fall outside them, and the visual takes part in slicer state synchronisation.

Tooltips

Node tooltips show the step, level, position, origin, inflow, outflow and share of the total (plus target and variance with a Target measure); link tooltips show source, destination, value and share of the total. Anything in Tooltip fields (Pro) is added. Report page tooltips are supported too, including on links: point the visual at a tooltip page and it will be used instead of the default card.

Navigating a large diagram

Zoom (buttons, Ctrl + mouse wheel, or + / − / 0 with the keyboard), native scrolling, a minimap at the top right and fit to view; a large diagram is fitted to the visual when it loads, and the diagram stays centered between the toolbar and the legend. Pro adds an in-diagram search and collapsing a mid-level node, which folds its branch away and recalculates the values downstream — usually a faster way to read a wide process than zooming out.

Variants panel (Pro)

Lists the top eight end-to-end paths by value. Selecting one traces it on the diagram, which answers “what actually happens most of the time” without rebuilding the model.

Accessibility

Keyboard navigation

The diagram is one tab stop. The arrow keys move along the flow and within a level, Home and End go to the first and last step, Enter or Space selects, Escape clears the selection, and + / − / 0 zoom. The focus ring is always visible, and screen readers hear each step with its level, value and, with a Target, its variance.

High contrast

When Power BI is in a high-contrast theme the visual takes its colours from the host palette rather than the Format Pane. Because fill cannot carry meaning in that mode, emphasis is re-coded as border weight: the dominant path and the selected node are distinguished by thicker outlines, not by colour.

The free tier draws your whole diagram — every node, every link, in a published report too. What Pro adds is the layer on top: the tools that only start to matter once a diagram is too big to read at a glance, and the wells that turn it into an analysis.

While you edit a report without a licence, a Pro feature you turn on is drawn working on the five largest nodes, two swimlanes and three variants, under a “Pro preview” watermark naming it, so you can see on your own data what you would be buying. Reading view draws the free result with no watermark, so a published report never uses a feature you have not paid for.

Pro is licensed through Microsoft AppSource. The licence is checked with the official Power BI licensing API, asynchronously and off the rendering path, and falls back to Free if the check cannot be completed. No external server is involved. See the Terms of Use for what each tier includes.

FAQ

My diagram is empty. What am I missing?

Flow Chart needs at least two fields in Levels. With one, it asks for a second; with none, it shows the start screen. Value is optional: without it each row counts 1.

The stages are in the wrong order.

Order comes from the order of the fields in the Levels well, not from the data. Drag the fields into the sequence the process actually follows.

Is the diagram limited in the free tier?

No. Since version 1.1.0.0 the free tier draws every node, in Power BI Desktop and in a published report alike. Earlier versions stopped at nine. If a diagram still looks cut off, use Fit in the toolbar (or press 0), or check the Power BI row limit for very large models.

I bought Pro but still see the watermark or no search box.

The licence check runs asynchronously, so give the visual a moment after the report loads. If it persists, confirm the Pro subscription is assigned to the account viewing the report — not only to the account that bought it — then refresh. If it still does not resolve, email support@tcviz.com with the report and the account in question.

Some arrows point backwards.

Those are cycles: transitions that return to an earlier stage. They are detected and drawn as discontinuous loops rather than being forced into the layer order, so rework and retry loops stay visible instead of distorting the diagram.

The KPI badge does not appear.

It needs a measure in the Target well. Also check that Show value badge in chip is on under Nodes.

Can I use more than six levels?

Yes. The Format Pane offers six level colours; levels beyond the sixth are drawn in the default node colour. The structure itself is not capped at six.

The swimlane bands are barely visible.

Band opacity is 6% by default, on purpose — bands are context, not data. Raise Band opacity % under Swimlanes if you want them more prominent.

The numbers look different after updating to 1.2.

Since 1.2 the default number format is the measure's own format (Value format → Model format). Choose Thousands there to get the 1.1 look back.

Where did the setup tips go?

They show only while editing, in a visual of at least 380 × 240. If you closed them, turn on Style template → Show setup tips.

Can I hide the toolbar?

Yes: Layout → Toolbar, or only the zoom buttons with Zoom buttons. Readers can still zoom with Ctrl + mouse wheel and + / − / 0.

Does the visual send my data anywhere?

No. There are no network calls, no telemetry and no browser storage. Everything is computed from the Power BI data view inside the report. The links on the start screen open only when you click them. The Privacy Policy spells this out.

My level images do not show.

Level images expects base64 strings that already live in your data model. The visual does not fetch images from URLs, so a column of links will not render.
