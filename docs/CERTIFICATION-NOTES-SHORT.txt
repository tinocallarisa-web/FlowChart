PLEASE READ FIRST - PRO PREVIEW (NEW IN 1.1.0.0)
Without a licence, IN EDIT MODE ONLY, a Pro feature is drawn WORKING under a "Pro
preview" watermark naming it. Intentional, not missing gating: it is how the user sees
what they would be buying. In reading view, before the licence resolves, and where
licences cannot be read (Publish to Web, embed, export) the FREE result is drawn with no
watermark. The gate is options.viewMode, not Desktop vs Service.

WHAT CHANGED IN 1.1.0.0
1. NO innerHTML AND NO LINT SUPPRESSION. The render built the DOM as text and injected
   it with innerHTML, with powerbi-visuals/no-inner-outer-html disabled by hand. It now
   uses createElement/createElementNS throughout, and escapeHtml() is gone: labels go by
   textContent and ids by setAttribute, which never interpret markup.
2. THE NODE CAP IS GONE. Free drew 9 nodes of N - a flow that does not exist. Free now
   draws the WHOLE diagram, published reports included.
3. NO PURCHASE PATH. Only notifyFeatureBlocked was called, so the user was asked to buy
   with no button. Order: clear -> banner -> Upgrade bar.

FREE VS PRO
Free: the complete diagram - nodes, links, layout, legend, zoom, fit, tooltips. Pro:
collapse/expand, node search, Variants, swimlanes, node images, KPI badge, extra
tooltips. Nothing that misrepresents the data is gated.

LICENCE
IVisualLicenseManager only. spIdentifier equal to or ending in ".flow-chart-tcviz",
Active and Warning accepted. Requested once, deferred, never in the render path; any
failure stays Free. Where it cannot be read nobody is asked to buy.

PRIVACY
No network calls, telemetry, cookies or storage; privileges: []. Level images only as
data:image base64, never fetched.

TESTING - FREE (no active plan)
1. Levels: 3+ fields and a Value measure, MORE than 9 nodes.
2. The whole diagram renders. In EDIT mode the scale tools (search, collapse handles,
   Variants) appear under the watermark, a banner names it, and after ~10 s the Upgrade
   bar appears.
3. Drag a field to Swimlane, Level images, Target or Tooltips: each renders WORKING
   under the watermark. Remove it and both go.
4. Reading view: the whole diagram, no scale tools, no watermark, no notice.
