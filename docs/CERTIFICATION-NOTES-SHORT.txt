WHAT CHANGED IN 1.0.4.0
Licence fix: spIdentifier is the full Service ID (publisher.offer.plan); we compared it
with the short Plan ID, so buyers stayed on Free. The purchase notification now waits
for the licence to resolve. No feature or data changes.

LICENCE
IVisualLicenseManager only: getAvailableServicePlans(), spIdentifier equal to or ending
in ".flow-chart-tcviz", accepting Active and Warning (grace period). Requested once, deferred, never in the render
path; any failure stays on Free. Where it cannot be queried (Publish to Web, embedding,
export) the free experience renders and nobody is asked to buy.

FREE VS PRO
Free: every feature, capped at 9 nodes kept as a connected sub-tree from the root, with a
neutral "Showing 9 of N nodes" note. No watermark. Pro: the same, no node cap.

PRIVACY
No network calls, no telemetry, no cookies, no local or session storage. Only the
dataView. Level images only as data:image base64, never fetched. privileges is [].

TESTING - FREE (submitted package, no active plan)
1. Levels: 3+ fields plus a Value measure, dataset with more than 9 nodes.
2. Expect 9 nodes as a connected sub-tree, the neutral count note, and Power BI's own
   licence notification - not a message in the chart.
3. Click a node and a link: other visuals cross-filter.
4. Right-click a node: the context menu opens, also after several refreshes.
5. Put a double quote in a level value: it renders as text, no broken markup.

TESTING - PRO (same package, active "flow-chart-tcviz" plan)
1. Same dataset: full diagram, the note disappears.
2. Add Target: KPI badge shows value and up/down %.
3. Add Swimlane: coloured bands. Open Variants, click one: it traces.
4. Collapse a mid-level node: downstream values and badges recalculate.
Without a plan, steps 2-4 also work on Free with 9 nodes or fewer.

Rendering events on every path of update(). Known warning, not a gap: Localizations -
single-language visual, stringResources empty on purpose.
