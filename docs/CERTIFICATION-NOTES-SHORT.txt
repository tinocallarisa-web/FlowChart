PRO PREVIEW
No licence, EDIT MODE ONLY: Pro layers drawn WORKING under a "Pro preview" watermark,
limited to the 5 largest nodes, 2 swimlanes, 3 variants. Reading view, unresolved licence
and Publish to Web/embed/export: FREE result, no watermark. Gate: options.viewMode.

WHAT CHANGED IN 1.2.0.0
1. 12 languages: capabilities keys + stringResources; own texts in the bundle.
2. Start screen without fields (links only on click, host.launchUrl) and setup tips in
   EDIT mode only. persistProperties only from a click in the tips (style.template,
   style.guide, linkSettings.showLabels, layoutSettings.showLevelHeaders/direction).
3. Templates, link labels, level headers, grid, backgrounds, toolbar/minimap and legend
   options. All free.
4. Color rules (Pro): node color by value, share or variance vs Target.
5. On-object formatting (subselection; in format mode a click never filters).
6. Numbers use the model format by default, dynamic format strings included.
7. Keyboard: one tab stop, arrow keys between steps, + / - / 0 zoom.
8. hostCapabilities.allowInteractions respected. ESLint plugin: 0 errors.

FREE VS PRO
Free: the complete diagram and everything in 3. Pro: collapse/expand, node search,
Variants, swimlanes, node images, KPI badge, extra tooltips, color rules.

LICENCE
IVisualLicenseManager only. spIdentifier equal to or ending in ".flow-chart-tcviz",
Active and Warning accepted. Requested once, deferred, never in the render path.

PRIVACY
No network calls, telemetry, cookies or storage; privileges: []. Images only as
data:image base64.

TESTING
1. No fields: start screen. One Levels field: message asking for a second one.
2. Levels 3+ fields, Value, MORE than 9 nodes. Free, EDIT mode: tools under the
   watermark, banner, then Upgrade bar after ~10 s. Reading view: free diagram, no mark.
3. Edit mode: tips at the bottom; click Clean, then Link labels: both apply. X hides them.
4. Format > Color rules > Rule 1 on: red on the largest nodes, under the watermark.
5. Format mode: click a node or a link: on-object panes open; nothing is filtered.
6. Click a node: the report filters; Ctrl+click adds; empty space clears.
