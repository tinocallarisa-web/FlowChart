How to Set Up the Visual

After importing the visual into your Power BI report, drag the following fields into the data roles:

Data RoleDescriptionRequired
LevelsOne field per hierarchy level, dragged in order (Level 1, Level 2, Level 3...). The visual builds the tree automatically from the column order; nodes sharing the same value at the same level are merged.Yes (at least 2)
Level imagesOptional base64 image per level, aligned by order with LevelsNo
ValueThe main metric, aggregated across each parent→child transitionYes
TargetEnables the KPI badge (value ▲/▼ variation% vs. target)No
SwimlaneGroups nodes into colored bands across the diagramNo
Tooltip fieldsExtra fields shown in node and link tooltipsNo

Frequently Asked Questions

Why is my diagram cut off / not showing all nodes?
The Free tier is limited to 9 nodes. Upgrade to Pro via Microsoft AppSource to unlock unlimited nodes. A message in the toolbar tells you when the diagram is being trimmed.
How does the visual decide the hierarchy?
By the order you drag fields into "Levels" — the first field is Level 1 (the root), the second is Level 2, and so on. Rows with the same value at the same level are automatically merged into one node.
How do I show KPI badges (target vs. actual)?
Drag a measure into the Target field. Nodes fed by rows with a target value switch their badge to show the actual value plus the ▲/▼ variation percentage, colored via the KPI up/down colors in the Format pane.
How do swimlanes work?
Drag a field into Swimlane. A node is only assigned to a band if every row that feeds it shares the same swimlane value; otherwise it stays neutral. Configure colors, opacity and label style under Swimlanes in the Format pane.
Can I collapse parts of the diagram?
Yes — any node with children shows a −/+ button on its edge. Collapsing hides the branch and recalculates the values, targets and link thickness upstream to reflect only what's still connected.
How do I activate my Pro license?
Purchase the Pro license on Microsoft AppSource. Once your subscription is active, the visual detects it automatically the next time you open or refresh your report — no additional steps required.
The visual is not rendering. What should I check?
Make sure at least two fields are in Levels and a measure is in Value. If the issue persists, try re-importing the .pbiviz file or contact us at support@tcviz.com.
